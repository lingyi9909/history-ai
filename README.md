# history-ai

AI 中国经典文学影像化项目。

## 当前阶段

**V1 已收敛为 Traffic-First：先用 15–30 天验证真实流量，再决定是否进入电影感技术深挖和 B 端商业验证。当前仍在最终复评，尚未正式开始发布。**

最新核心问题不再是：

> “我们能不能一开始就把完整商业闭环设计好？”

而是：

> **真实平台用户到底愿不愿意持续消费这类 AI 中国经典文学影像？**

如果流量没有正向且可重复的信号，后续精品化、跨镜头一致性、B 端订单都不继续投入。

## 唯一主评审入口

### [History AI V1 多人评审包（Traffic-First 版）](docs/review/2026-08-30-history-ai-v1-review-pack.md)

这是当前最新执行基线。

当前 Phase 1：

- 周期：15 天初判，最长 30 天；
- 现金预算：约 ¥2,000–3,000；
- 内容：10–15 条 30–60 秒短视频；
- 首批题材：《木兰诗》《蜀道难》《赤壁赋》《桃花源记》《将进酒/出师表》；
- 主要平台：抖音 + 快手，其他平台低成本同步；
- Organic First，不用投流制造“成功”；
- 前 5 条建立 Baseline，后续验证是否可重复；
- 重点看观看质量、分享/收藏、关注、评论与系列需求，而不是只看播放量；
- Day 15 信号清晰就做 PASS / PIVOT / STOP，不机械做满 30 天。

## Traffic Gate 通过后才做什么

### Phase 2：差异化 / 技术 / 成本

才正式验证：

- 《电影感落地标准 V1》；
- 8–12 镜头跨镜头一致性技术 Spike；
- 普通版 vs 精品版 A/B；
- 30–50 人盲测；
- 现金成本 + 人工工时 + CPUS；
- 必要时做 1 条 ≤5 分钟精品中视频。

### Phase 3：B 端付费

才系统验证：

- 客户为什么付费；
- 中小 B 是否愿意试单；
- 质量 / 价格 / 速度的真实优先级；
- 90 天争取真实付费试单；
- 约 180 天再挑战万元级正式订单。

## 当前决策原则

- 不把“课本古文”题材本身当护城河；
- 不预设“电影感”一定是最终正确差异化；
- 不在流量尚未验证前做过重的技术工程；
- 不在流量尚未验证前要求 B 端商业闭环；
- 不把 3–10 分钟精品中视频设成 Phase 1 必交付；
- 从 Day 1 记录现金成本、人工工时、重试和废片率；
- 从 Day 1 执行 AI 标识、版权和内容安全底线；
- 多人复评如果没有新的高共识重大 blocker，就冻结 Phase 1，开始真实发布。
