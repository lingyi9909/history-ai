# history-ai

AI 中国经典文学影像化项目。

## 当前阶段

**V1 多人评审中，尚未进入正式内容生产。**

当前要验证的核心命题不是“古文 AI 视频有没有流量”，而是：

> 在已经拥挤的 AI 古文视频赛道里，电影感叙事、跨镜头一致性、系统化视觉设计和可重复商业交付能力，是否能形成用户可感知、客户愿意付费的质量差异。

## 当前明确决策

- 不把“课本古文选题”本身当差异化或护城河；
- 《木兰诗》《赤壁赋》《蜀道难》为 P0 主力；
- 《滕王阁序》为 P1；
- 《桃花源记》为红海 Control 对照组；
- 第一周必须完成同题材 A/B、20–30 人盲测和真实成本验证；
- 30 天同步做 B 端主动获客，不被动等待询盘；
- 不开发 App / SaaS / 自研模型；
- 不提前做几十集连续 AI 微短剧；
- 多人评审收敛前不扩大预算。

## 决策门

多人评审结束后，只处理真正阻塞 MVP 的核心问题。

如果没有新的重大 blocker，下一步直接进入：

> **首批 P0 Production Package + 《桃花源记》对照实验 + 第 1 周真实生产验证。**
