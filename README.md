# history-ai

AI 中国经典文学影像化项目。

## 当前阶段

**V1 首轮审核结论：B（有条件通过）。三个 blocker 已完成方案整改，当前等待复验；尚未进入正式内容生产。**

核心目标：验证是否能用生成式 AI 持续生产具有可感知质量差异的中国经典文学/历史文化影像，并形成：

1. 内容流量资产；
2. AI 文化影像商业制作能力；
3. 长期视觉 IP。

## 首轮审核三个 blocker

### 1. 差异化验证缺失

已修正：承认“课本古文 AI 视频”赛道已经拥挤；不再把题材本身当差异化。第 1 周新增同题材 A/B 对照、非团队盲测和差异化 Gate，验证“电影感精品叙事”是否真的能被用户感知。

### 2. B 端主动获客路径缺失

已修正：从纯 Inbound 改为 Inbound + Outbound。30 天内建立 ≥30 个潜在客户、≥10 次有效主动触达、≥5 次有效沟通、≥2 次需求访谈、≥1 份真实报价/提案；90 天万元首单保留为挑战结果指标。

### 3. 首批选题风险

已修正：《桃花源记》从主打降级为红海对照组；《木兰诗》《赤壁赋》《蜀道难》作为 P0 主力，《滕王阁序》作为 P1 探索。

## 本轮复验边界

只复验三个 blocker 是否关闭，不扩大方案范围。

复验通过后，才进入首批内容的 Production Package 与实际制作。
