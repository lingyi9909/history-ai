# history-ai

AI 中国经典文学影像化项目。

## 当前阶段

**V1 商业与内容方案评审中，尚未进入规模化实施。**

核心目标：验证是否能用生成式 AI 低成本持续生产高质量的中国经典文学/历史文化影像内容，并形成：

1. 内容流量资产；
2. AI 文化影像商业制作能力；
3. 长期视觉 IP。

## 评审材料

- [History AI V1 方案设计](docs/superpowers/specs/2026-08-30-history-ai-v1-design.md)
- [AI 视频赛道与政策调研备忘录](docs/research/2026-08-30-ai-video-market-and-policy-notes.md)

## 本轮评审重点

请重点挑战以下问题，而不是只判断“AI 视频有没有前景”：

- “语文课本电影化”是否足够差异化；
- 30 天 / ¥5,000 / 20–24 条内容是否足以验证；
- B 端文化、文旅、教育订单能否成为早期现金流；
- 是否应该更早进入连续微短剧；
- KPI 与止损线是否合理；
- 版权、AI 标识与内容合规是否有遗漏；
- 哪些资产能形成真正护城河；
- 90 天首笔万元订单是否是合理商业目标。
