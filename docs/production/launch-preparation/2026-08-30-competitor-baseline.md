# 1. 使用规则

这张表只回答三个问题：

1. 我们准备做的题材 / 表达是否已经高度同质化？
2. 同类内容的大致表现区间是否存在极大离散？
3. 哪些内容包装、叙事结构和标题方式值得作为外部参照？

禁止使用方式：

> “竞品 1 万播放，所以我们不到 1 万就是 FAIL。”

Phase 1 的 PASS / PIVOT / FAIL / INSUFFICIENT 仍以自身账号的可重复用户消费信号为核心。

# 3. 当前可见信号

## 3.1 同题材表现离散极大

《桃花源记》样本从数千到 26 万级都有；《将进酒》也同时存在十万级和低量作品。

这说明：

> **题材本身不能解释流量，账号基础、包装、叙事、制作质量和平台分发都会显著影响结果。**

因此 Phase 1 不设置跨账号统一播放阈值。

## 3.2 “AI + 古文”已经高度商品化

公开样本已经覆盖：

- 全文逐句还原；
- AI 绘画配原文；
- 4K / 史诗化动画；
- 穿越 Vlog；
- AI 微电影；
- 儿童教育动画；
- 制作挑战 / 幕后过程。

History AI 不能把“我用 AI 把古文做成视频”本身当成卖点。

## 3.3 表现较强的案例通常还有第二层钩子

公开样本中值得关注的包装包括：

- “把课文拍成电影”；
- “挑战5小时一个人完成”；
- “穿越现场 / Vlog”；
- “看完再背课文”；
- “下一篇想看哪篇”。

因此 Sample #1 既要有视觉质量，也需要清楚的内容承诺：

> **把背过的文字拍成电影。**

## 3.4 长片可以成立，但不是 Phase 1 的证据要求

《桃花源记》12分半完整 AI 微电影出现明显播放信号，证明长篇古文影像并非天然无人看；但其制作周期达到约两周半，不能用来反推 Phase 1 的 30 秒短视频经济性。

长片仍保留到 Traffic Gate 通过后再验证。

# 4. 对《将进酒》Launch Check 的直接启示

## 应该做

- 第一秒就给强视觉 / 强尺度，而不是先上片头；
- 控制 30 秒，不全文朗诵；
- 只保留最强 3–4 句；
- 用具体场景和人物承接原文，不做纯 AI 图集；
- 标题直接说明产品承诺：“如果《将进酒》被拍成电影”；
- 结尾问下一篇，但数据记录时区分 CTA 回答和自然催更。

## 不应该做

- 标题只写“AI《将进酒》”；
- 把“用了哪个模型”当主要内容价值；
- 做成 2–4 分钟全文还原作为 Sample #1；
- 模仿现有“AI古文史诗 / 刻在DNA里”等成熟模板文案；
- 因竞品某条达到十万播放，就给自己设十万播放硬门槛。

# 5. Phase 1 持续更新字段

正式发布后，每发现一个高度相关竞品，只在下列情况加入表格：

- 与 Batch 1 五题材直接相同；
- 表达方式与我们高度相似；
- 出现明显异常高 / 低表现，值得解释；
- 同账号出现多个可重复成功样本。

不要把竞品表扩大成无限市场研究。

目标规模长期维持在：

> **10–25 条高相关样本即可。**
