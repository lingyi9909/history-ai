# History AI V1 Phase 1｜Launch Readiness Checklist

> 状态：Ready to Use  
> 适用：第一条 Sample 发布前 + 后续每条发布前复用

---

# 1. 账号与品牌一次性设置

## 名称

优先：

> **课本电影院**

如平台已被占用，按以下顺序尝试：

1. 课本电影院AI
2. 课本电影院Studio
3. 课本电影院影像

不要使用带大量数字、下划线或模型品牌的名称。

## 简介

推荐：

> 把你背过的文字，拍成电影。  
> AI × 中国经典文学｜持续更新

Phase 1 不在简介里写“最强AI”“100%历史还原”“电影级制作”等无法稳定证明的承诺。

## 头像方向

- 简洁文字 / 印章感品牌标识；
- 不使用教材出版社 Logo；
- 不使用现成影视角色；
- 小尺寸仍可识别。

## 封面体系

统一模板：

- 主画面：作品最强单帧；
- 主标题：“如果《XXX》被拍成电影”；
- 角标：“课本电影院 0X”；
- 文字面积不超过画面约 25%；
- 不模仿教材封面或统编版版式。

Phase 1 中途不随意重做品牌视觉。

---

# 2. 发布前硬检查

以下任一关键项失败，不发布。

## 内容质量

- [ ] 视频长度在当前实验允许范围内；
- [ ] 开头 1–3 秒有明确视觉 / 情绪钩子；
- [ ] 没有明显脸部、肢体、手部畸形；
- [ ] 没有影响观看的跳帧、漂移、角色突变；
- [ ] 视觉风格基本统一；
- [ ] 旁白清晰，音乐不压人声；
- [ ] 字幕无错字；
- [ ] 不依靠模型生成画面中的汉字作为正式字幕。

## AI 合规

- [ ] 按发布当日平台规则主动声明 AI 生成内容；
- [ ] 使用平台要求的 AI 内容标识功能；
- [ ] 未人为移除应保留的生成 / 平台标识；
- [ ] 所有实验样本统一执行，不把合规作为 A/B 变量。

## 版权

- [ ] 原文属于公有领域或已取得使用许可；
- [ ] 改编脚本为原创；
- [ ] 未直接使用教材插图 / 特定教材版式；
- [ ] 未复刻现代影视、动漫、游戏角色造型；
- [ ] 无明星脸或未经授权可识别真人；
- [ ] 背景音乐来源和使用权明确；
- [ ] AI 配音音色来源及商用条件明确；
- [ ] 未使用未经授权真人声音克隆。

## 发布变量

- [ ] 标题符合当前统一风格；
- [ ] 封面符合当前统一模板；
- [ ] 时长与同批样本差异不过大；
- [ ] 发布时间处于当前测试窗口；
- [ ] 标签控制在少量高相关范围；
- [ ] Organic / Paid 已明确标记，本轮默认 Organic。

---

# 3. 评论区固定动作

发布后可以置顶：

> 下一篇，你最想看哪篇课文被拍成电影？

记录数据时必须区分：

- 主动点题；
- 主动催更 / 要完整版；
- CTA 回答；
- AI 猎奇；
- 纠错；
- 普通情绪评论。

不要把所有“下一篇XX”都算自然系列需求。

---

# 4. 冷启动规则

- 前 3 条标记 `Calibration Sample`；
- 正常发布、正常记录；
- 不发无关内容养号；
- 不刷赞、刷评论、互关制造权重；
- 不蹭无关热点污染垂直标签；
- 前 3 条不能单独决定 PASS / FAIL；
- 分发不足时进入 `INSUFFICIENT`，不直接判内容失败。

---

# 5. 发布后时间点

每条至少回填：

- 2h
- 24h
- 72h

Day 10：Health Check。  
Day 15：Early Gate。  
最长 Day 30：正式 Traffic Gate。

---

# 6. Phase 1 Freeze

以下建议默认进入 Backlog，不因此延迟 Sample 发布：

- 换第二平台；
- 改品牌名；
- 加复杂 Character Bible；
- 做 3–10 分钟精品片；
- 开发自动化工具；
- 研究 B 端报价；
- 做海外版本；
- 继续扩大题库；
- 追求电影工业级一致性。

只有以下情况允许阻塞发布：

> **法律 / 平台合规风险，或会直接导致本轮流量实验结果失真的重大问题。**
