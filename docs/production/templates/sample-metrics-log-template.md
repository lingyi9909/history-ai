# 5. Content Diagnosis

## 3秒留存 vs 完播

选择最接近的一项：

- [ ] 3秒高 + 完播高：开头和主体都有效；
- [ ] 3秒高 + 完播低：开头有效，主体撑不住；
- [ ] 3秒低 + 完播相对高：内容对留下的人有效，但首屏 / 开头弱；
- [ ] 3秒低 + 完播低：选题 / 开头 / 表达整体需要调整；
- [ ] 样本不足，无法判断。
