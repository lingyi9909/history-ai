> 状态：Review Ready / 待重新评审  
> 日期：2026-08-30  
> 分支：`develop`  
> 用途：**当前 V1 唯一主评审入口与最新执行基线。**  
> 重要变化：根据多轮评审和最新决策，V1 第一阶段从“30 天同时验证内容、技术、B 端商业闭环”收敛为“15–30 天优先验证真实市场流量”。旧设计和旧整改记录仅用于追溯；如有冲突，以本文件为准。

---

# 0. 本轮真正要评审什么

History AI 当前还没有进入正式规模化生产，也不开发 App / SaaS / 自研模型。

本轮只判断一件事：

> **是否值得先投入 15–30 天、约 2,000–3,000 元现金预算，发布 10–15 条真实短视频，验证用户是否愿意持续消费“AI 中国经典文学影像”这一内容形态。**

第一阶段暂时不要求证明完整商业模式，不要求拿 B 端订单，也不要求证明 3–10 分钟精品片可以规模化生产。

原因很简单：

> **如果真实用户连短内容都不愿意看，后续“电影感技术路线、精品长内容、B 端付费”都没有继续投入验证的必要。**

---

# 1. 一句话定义项目

History AI 不是一个 AI 视频工具项目。

它希望长期验证：

> 能否利用生成式 AI，把中国经典文学、古文、名著、神话、历史与文化故事制作成具有较高审美和叙事价值的影像内容，并逐步形成内容流量、文化影像商业制作能力和长期视觉 IP。

第一阶段内容品牌暂定：

> **课本电影院**

口号：

> **把你背过的文字，拍成电影。**

但“课本古文”只是一组高认知测试题材，不是护城河。

---

# 2. 已经确认的事实与不再争论的前提

## 2.1 赛道已经拥挤

原方案曾认为“课本古文 AI 视频竞争相对没那么拥挤”。该判断已废止。

当前基线认知：

- AI 古文 / 课本视频已经有大量账号和教程化复制；
- 《桃花源记》等题材已经高度同质化；
- “选题库”本身是公共信息，不构成壁垒；
- Prompt 和单一模型技巧也不构成长久壁垒；
- 技术能力会持续商品化。

因此第一阶段不是验证“AI 古文有没有人看”这个抽象问题，而是验证：

> **我们做出的这批内容，在真实平台上是否能获得可重复的用户消费信号。**

## 2.2 不预设“电影感”一定成立

前几轮评审一致认为“电影感”过于抽象，而且跨镜头一致性、精品制作成本都有技术不确定性。

本版不再把“电影感一定是正确差异化”作为 Phase 1 前提。

Phase 1 只把它视为一种候选表达方式，与以下方式一起测试：

- 电影化场景叙事；
- 视觉奇观 + 名句；
- 强情绪叙事；
- 高审美单镜头 / 组镜头 + 旁白；
- 经典名场面重构。

哪种表达方式能获得流量，由真实数据决定。

## 2.3 不预设 B 端一定会买

文旅、博物馆、出版、教育、国风品牌、游戏等确实存在文化内容制作需求，但：

- 大 B 采购周期长；
- 可能存在资质、招标、案例门槛；
- C 端流量与 B 端成交不是自然等号；
- 客户真正愿意为什么付钱，需要后续访谈和试单验证。

因此 B 端商业验证后移，不作为 Phase 1 的生死指标。

# 3. V1 总体路线：四阶段漏斗

```text
Phase 1：15–30 天真实流量验证
        ↓
Traffic Gate
        ↓ PASS
Phase 2：差异化 / 技术 / 成本验证
        ↓
Quality & Economics Gate
        ↓ PASS
Phase 3：精品案例 + 中小 B 付费验证
        ↓
Commercial Gate
        ↓ PASS
Phase 4：扩大内容产能 / B端销售 / IP探索
```

**当前只准备执行 Phase 1。**

Phase 2–4 只定义进入条件，不提前投入大量资源。

---

# 4. Phase 1：15–30 天真实流量验证

## 4.1 核心目标

Phase 1 只回答三个问题：

1. **用户愿不愿意看？**
2. **哪些题材和表达方式更容易获得流量和互动？**
3. **正向信号能否重复，而不是只出现一条偶发爆款？**

暂时不要求回答：

- 电影感是否形成最终护城河；
- 10+ 镜头一致性能否规模化；
- 5 分钟精品片是否经济；
- B 端客户最终愿意付多少钱；
- 90 天能否获得万元订单。

这些问题只有 Traffic Gate 通过后才值得继续验证。

## 4.2 周期

目标周期：**15 天初判，最长 30 天。**

不是默认一定做满 30 天。

- Day 15 信号足够清晰：直接 PASS / PIVOT / STOP；
- Day 15 有部分正向信号但不够稳定：延长到 Day 30；
- Day 15 已经出现连续明显负信号：不因为“计划写了 30 天”继续烧预算。

## 4.3 现金预算

Phase 1 预算上限：**2,000–3,000 元。**

5,000 元仍作为整个 V1 的总实验储备，但不一次性释放。

建议：

| 项目 | Phase 1 建议 |
|---|---:|
| AI 视频生成 / 重试 | ¥1,200–1,800 |
| 关键帧 / 角色参考 | ¥200–300 |
| 配音 / 音效 / 音乐 | ¥200–300 |
| 工具会员 | ¥200–300 |
| 失败 / 重试机动 | ¥200–400 |
| 合计 | ¥2,000–3,000 |

不为了“把预算花完”而提高制作复杂度。

## 4.4 内容量

Phase 1 目标：**10–15 条 30–60 秒短视频。**

这是目标区间，不是硬性生产 KPI。

原则：

- 先发 5 条形成初始基线；
- 再根据真实数据，把后 5–10 条集中到更有信号的题材 / 表达方式；
- 不机械日更；
- 不为了凑数制作明显低质量内容；
- 如果第 8–10 条已经得到非常清楚的 FAIL 信号，可以提前结束。

原方案“20–24 条 + 2 条 3–10 分钟中视频”不再是 Phase 1 要求。

# 5. Phase 1 的内容实验矩阵

Phase 1 不只测试题材，还测试“题材 × 表达方式”。

## 5.1 第一批 5 个题材

### P0：人物 / 动作

**《木兰诗》**

验证：人物、动作、战争、亲情 / 身份情绪是否有传播力。

### P0：视觉奇观

**《蜀道难》**

验证：AI 大场景和奇观是否能成为强点击 / 停留因素。

### P0：氛围 / 情绪

**《赤壁赋》**

验证：较克制、审美型、情绪型内容是否有用户空间。

### Control：红海对照

**《桃花源记》**

验证：在高度同质化题材下，我们的处理方式能否获得市场信号。

### Emotion：强情绪 / 名句

**《将进酒》或《出师表》**

二选一，验证“强情绪 + 高认知文本”是否比纯画面奇观更容易传播。

《滕王阁序》等暂放第二批，根据数据再决定是否进入。

## 5.2 候选表达方式

Phase 1 至少覆盖三种，而不是所有视频都按同一模板：

### A. 电影化场景叙事

以具体人物和事件推进，减少解释，强化沉浸。

### B. 视觉奇观 + 经典名句

节奏更快，以画面冲击和高认知原文建立记忆点。

### C. 情绪叙事 + 高审美画面

不强求复杂连续镜头，更强调情绪、声音和文案。

必要时可加入：

### D. 名场面重构

选一个强戏剧瞬间做 30–45 秒短场景。

Phase 1 的目标不是找到“唯一正确格式”，而是找出最值得 Phase 2 深挖的 1–2 种。

---

# 6. Phase 1 制作质量：够用，不做过度工程化

多轮评审提出了电影感标准、跨镜头一致性 Spike、多模型路由等问题。这些问题重要，但不应在真实流量尚未验证前把第一阶段变成技术研发项目。

Phase 1 采用“最低成片质量线”：

- 画面没有明显畸形、穿帮或严重 AI 伪影；
- 同一条视频的核心人物在关键镜头中基本可识别；
- 视觉风格基本统一；
- 字幕、旁白、音乐、音效达到正常发布质量；
- 叙事能独立看懂或形成明确情绪；
- 不直接模仿现代影视、游戏、动漫中的受保护造型和美术；
- 不为了追求 100% 一致性无限重生成。

Phase 1 不要求：

- 20+ 镜头长连续叙事；
- 每条都建立复杂 Character Bible；
- 每条都做多模型镜头级路由；
- 逐帧人工修补；
- 电影工业级参数化标准。

如果某个技术动作显著提高制作时间，却没有证据表明它能提升真实流量，Phase 1 不优先做。

# 7. 平台发布策略

## 7.1 主平台

建议至少选择 **2 个短视频平台**作为主要验证渠道，避免单平台算法偶然性。

优先：

- 抖音；
- 快手。

如果账号和运营精力允许，可低成本同步：

- B站；
- 小红书；
- 视频号。

但每个平台的数据独立判断，不把不同平台播放量直接相加。

## 7.2 Organic First

Phase 1 核心判断尽量使用**自然流量**。

原则：

- 首轮发布不靠付费投流制造“成功”；
- 如后续需要测试投流，只能单独标记为 paid experiment；
- Organic 数据与付费数据分开记录；
- 不用付费曝光替代内容本身的验证。

## 7.3 发布变量尽量稳定

尽量控制：

- 时长区间；
- 标题风格；
- 封面质量；
- 发布时间窗口；
- 标签数量；
- 账号简介和品牌定位。

不是追求学术实验，而是减少明显干扰变量。

# 8. Traffic Metrics：第一阶段真正看的数据

每条至少记录发布后 2h / 24h / 72h 的平台数据（平台能提供多少记录多少）：

- 曝光 / 播放；
- 前 3 秒留存；
- 平均观看时长；
- 平均观看比例；
- 完播率；
- 点赞；
- 评论；
- 分享；
- 收藏；
- 主页访问；
- 新增关注；
- 评论中主动点题 / 催更 / 要完整版的数量；
- 是否有人主动提到画面、故事、情绪、电影感或“AI 技术猎奇”。

不同平台指标定义可能不同，**只在同一平台内做纵向比较。**

---

# 9. Traffic Gate：如何避免被一条爆款骗到

不设置一个跨所有平台都通用的绝对播放量阈值。

原因：新账号、平台、题材、发布时间都会影响绝对播放。

采用“首批基线 + 重复性”判断。

## 9.1 基线

前 5 条作为 Baseline Batch。

记录每个平台的中位数表现。

后续内容与该平台自己的基线比较。

## 9.2 PASS

满足以下原则可进入 Phase 2：

1. **至少 2–3 条不同作品出现明确高于基线的正向信号，而不是只有一条爆款；**
2. 正向信号至少同时体现在“观看质量”与“互动 / 关注”中的两类指标，而不是只有播放量；
3. 至少有 1 个题材 / 表达方式能够被第二次复现；
4. 评论或关注行为证明用户至少有一部分是在消费“内容本身”，而不仅仅围观 AI 技术；
5. 生产成本仍处于可继续实验的范围。

可参考的内部相对信号（不是行业统一标准）：

- 后续作品 72h 播放达到同平台首批中位数约 2 倍以上；或
- 完播 / 平均观看比例明显高于首批中位数；或
- 分享 + 收藏 / 关注转化明显高于首批中位数；
- 且这种优势能在不止一条内容上复现。

## 9.3 STRONG PASS

出现以下情况之一，可提前进入 Phase 2：

- 有一条明显突破账号基线（例如达到基线数倍至十倍），同时至少还有 2 条有一致方向的正信号；
- 同一表达方式在两个不同题材上都显著优于基线；
- 用户主动大量点题、催更、关注系列。

## 9.4 CONDITIONAL

- 只有一条高播放，其余内容没有复现；
- 播放高但完播、分享、收藏、关注弱；
- 盲目视觉奇观有点击，但用户没有系列消费意愿；
- 某个平台有效、另一个平台完全无信号。

处理：延长到 Day 30，集中验证最强的 1–2 个假设，不扩大预算。

## 9.5 FAIL / PIVOT

发布约 10 条后仍出现：

- 没有任何可复现的正向信号；
- 完播、分享、收藏、关注持续弱；
- 用户没有任何催更 / 点题 / 系列需求；
- 只有“AI 好厉害”而没有内容消费信号；
- 提高制作成本也没有获得明显数据增益。

则不进入精品电影化路线。

可选择：

- 调整为“极致单镜头美学 + 强叙事文案”；
- 改题材池；
- 改内容定位；
- 或停止项目。

# 10. Phase 1 仍然必须记录成本

虽然第一阶段只验证流量，但不能为了追流量完全忽略生产经济性。

每条记录：

- 现金生成成本；
- 生成 / 重试次数；
- 废片数量；
- 最终可用秒数；
- 脚本工时；
- 画面生成工时；
- 后期工时；
- 总人工工时；
- Cost per Usable Second（CPUS）；
- 单条最终总工时。

**人工工时不计入 2,000–3,000 元现金预算，但必须计入经济性分析。**

Phase 1 不设武断的“CPUS 超过 X 元就死亡”阈值。

原因：真正商业判断需要结合未来客户愿付价格和目标毛利。

当前只做两件事：

1. 找出哪种内容结构最耗时、废片率最高；
2. 确认流量提升是否需要成倍增加成本。

# 11. Phase 2：只有 Traffic Gate PASS 才进入

Phase 2 才正式回答前几轮评审提出的“电影感到底是什么、能不能低成本实现”。

## 11.1 《电影感落地标准 V1》

拆成至少 5 个维度：

1. 镜头语言；
2. 光影 / 美术；
3. 构图 / 景别；
4. 剪辑节奏；
5. 声音设计。

每个维度同时定义：

- 制作要求；
- 可观察结果；
- 盲测评分项。

不把“电影感”只写成主观形容词。

## 11.2 跨镜头一致性技术 Spike

不预设“做不到”，也不预设“模型宣传就等于可用”。

用 45–60 秒、约 8–12 个镜头的连续片段实测：

- 面部身份；
- 服饰；
- 体型；
- 场景连续性；
- 动作衔接；
- 重生成次数；
- 人工修补时间；
- 最终可交付成本。

核心判断不是某个没有依据的“70% 一致率”，而是：

> **达到用户不明显出戏的连续叙事，需要付出多少真实成本。**

## 11.3 A/B + 盲测

Traffic Gate PASS 后，再选择已经有真实信号的题材做：

- 普通快速版；
- History AI 精品版。

严格控制题材 / 核心脚本等变量。

盲测建议 30–50 人，若成本允许可更多；其中可加入少量 B 端从业者。

要验证：

> 质量提升是否真的带来用户偏好提升，以及这种提升是否值得增加的成本。

## 11.4 精品中视频

不再是 V1 Phase 1 硬性交付。

只有同时满足：

- Traffic Gate PASS；
- 技术路线可行；
- 短内容精品化带来明显增益；
- 成本没有失控；

才制作 **1 条上限约 5 分钟的精品中视频**作为能力验证和后续案例。

否则不做。

---

# 12. Phase 3：B 端商业验证后移

内容流量和质量路线被初步验证后，才进入主动商业验证。

## 12.1 先验证客户为什么付钱

优先访谈 5–8 个潜在客户，验证：

- 更低价格是否是核心动因；
- 更高质量是否值得溢价；
- 更快交付是否更重要；
- AI 是否被允许；
- 历史准确性 / 品牌安全要求；
- 对案例和资质的要求；
- 采购决策链；
- 可接受预算；
- 是否愿意付费试单。

先理解购买逻辑，再做 B 端 Demo，不反过来。

## 12.2 客户优先级

早期成交优先选择决策链较短的中小 B：

- 国风消费品牌；
- 游戏 / 文化娱乐公司；
- 民营文旅项目；
- 文化创业公司；
- 民营文化空间；
- 独立出版 / 内容工作室；
- 教育内容公司；
- 中小文旅运营公司。

政府文旅、大型博物馆、大出版社等仍作为需求研究对象和中长期客户，但不把 30–90 天内成交作为硬要求。

## 12.3 商业目标调整

原“90 天首笔 ≥1 万元订单”不再作为硬成败线。

建议：

- **Phase 3 / 90 天内：争取 1 个真实付费试单，金额不限；**
- 获得明确报价讨论、采购流程确认、正式试单也记为强信号；
- **约 180 天：再挑战首笔 ≥1 万元正式订单。**

# 13. 合规与版权底线

Phase 1 即执行，不因为“只是试流量”放松。

## 13.1 AI 标识

按照现行法律法规与各平台规则完成 AI 生成内容显著标识 / 声明。

不自行发明“固定必须展示几秒”等没有明确官方依据的规则；发布前核对平台当期要求。

## 13.2 版权

Phase 1 原则：

> **只基于公有领域古典原文 / 史料 + 原创改编 + 自行生成或合法授权素材。**

不得直接复制现代影视 / 游戏 / 动漫中的：

- 演员形象；
- 角色造型；
- 美术设计；
- 原创剧情；
- 配乐；
- 海报 / 插画；
- 现代注释本 / 译本中的受保护表达。

## 13.3 声音

记录真人配音 / AI 合成方式及商用授权。

禁止未经授权克隆可识别真人声音。

## 13.4 内容安全 / 历史准确性

涉及明确历史人物、民族、宗教、重大历史事件时增加事实与内容安全检查。

Phase 1 不追求学术纪录片精度，但不得为了“魔改吸睛”制造明显错误史实或高风险表达。

# 14. 竞品基准记录

Phase 1 建立轻量竞品表，至少记录 10–20 个同类作品 / 账号：

- 题材；
- 时长；
- 表达方式；
- 公开播放量；
- 点赞 / 评论 / 收藏（能看到多少记录多少）；
- 封面 / 标题结构；
- 是否电影化；
- 是否纯 AI 奇观；
- 更新频率；
- 商业化迹象。

目的不是“抄竞品”，而是避免把市场已经普遍存在的表现误认为自己的独特创新。

平台无法公开获取的完播率等指标不要猜测。

# 15. Phase 1 时间表

## Day 1–3：准备与首批制作

- 完成账号定位和基础视觉；
- 建立竞品基准表；
- 确定首批 5 个题材；
- 完成 2–3 条首发内容；
- 建立统一数据 / 成本记录表。

## Day 4–10：Baseline Batch

- 发布首批约 5 条；
- 每条记录 2h / 24h / 72h 数据；
- 不因单条表现立即大改方向；
- 第 5 条后形成首个同平台基线。

## Day 11–15：第一次复制验证

- 根据前 5 条选择最强的 1–2 个题材 / 表达方式；
- 再发布 3–5 条相邻实验；
- 判断信号能否复现。

### Day 15 Checkpoint

- PASS：进入 Phase 2；
- CONDITIONAL：继续到 Day 30；
- FAIL：Pivot / Stop。

## Day 16–30：仅在信号不清晰时继续

- 聚焦最强方向；
- 不继续平均分配题材；
- 必要时做少量同题材表达方式对比；
- 最大目标是回答“能不能复现”，不是继续堆数量。

# 16. V1 当前 Stop-Loss

Phase 1 立即停止扩大投入的情况：

1. 约 10 条后没有任何重复正信号；
2. 作品必须持续大幅加钱 / 加工时才能勉强获得普通数据；
3. 用户明显只围观 AI 技术、不消费内容；
4. 内容方向存在不可接受的版权 / 合规风险；
5. 生产过程严重依赖不可复制的人工修补。

注意：

> **停止“当前路线”不等于停止整个 History AI。**

可以先 Pivot 表达方式，再决定项目是否彻底停止。

# 17. 只有通过 Phase 1 后才值得形成的长期壁垒

可能形成壁垒的不是“我们会用 AI”。

真正值得继续积累的是：

- 对用户题材 / 情绪偏好的真实数据；
- 系列品牌认知；
- 剧本和镜头改编方法；
- Character / Visual Bible（在需要长期角色时）；
- 可重复的精品制作 SOP；
- 真实生成失败 / 成本数据库；
- B 端客户案例和信任关系；
- 商业交付能力。

这些都必须建立在“市场先愿意看”的基础上。

# 18. 本轮评审希望重点挑战的问题

请不要继续把评审重心放在 Phase 2 / Phase 3 的细节优化上。

优先挑战：

1. 先用 15–30 天验证真实流量，这个顺序是否正确？
2. 10–15 条内容是否足够拿到方向性信号？
3. 2,000–3,000 元 Phase 1 预算是否合理？
4. 首批 5 个题材是否覆盖足够不同的用户需求？
5. 三到四种表达方式是否设计合理？
6. Traffic Gate 是否能避免被单条爆款误导？
7. “首批 5 条建立基线 → 后续复制验证”的方法是否合理？
8. Phase 1 是否仍然做得过重，哪些动作可以再删除？
9. Phase 1 是否过轻，以至于好内容还没来得及被验证就被误杀？
10. 抖音 + 快手作为主要流量验证平台是否合适？
11. 成本和人工工时记录是否足以支撑后续商业判断？
12. 把电影感标准、跨镜头 Spike、盲测后移到 Phase 2 是否合理？
13. 把 B 端访谈 / 试单后移到 Traffic Gate 之后是否会错过重要信息？
14. 当前最大的流量验证偏差是什么？
15. 如果 Phase 1 是你自己的 15–30 天和 2,000–3,000 元，你会不会做？为什么？

# 19. 评审结论格式

请明确给：

- **A. 通过：可以直接开始 Phase 1 流量验证；**
- **B. 有条件通过：存在必须先修的 Phase 1 blocker；**
- **C. 不建议执行：Traffic-First 方案本身仍有根本问题。**

如果给 B，请严格区分：

### 真正 Blocker

不修就会导致 Phase 1 无法得出可信结论的问题。

### 非阻塞优化

可以边做边优化、不应继续拖延真实市场验证的问题。
