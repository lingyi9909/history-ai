# 1. 一句话定义项目

History AI 不是一个“AI 视频工具项目”。

它要验证的是：

> 能否利用生成式 AI，以小团队和较低成本，把中国经典文学、古文、历史和文化故事制作成具有明显电影感、跨镜头一致性和系列品牌感的影像内容，并进一步转化为内容流量、B 端文化影像订单和长期视觉 IP。

第一阶段对外内容品牌暂定：

> **课本电影院**

口号：

> **把你背过的文字，拍成电影。**

---

# 2. 首轮审核后最重要的事实修正

原始方案曾认为“语文课本 / 古文电影化竞争相对没那么拥挤”。

**该判断现已废止。**

外部案例已经证明：

- “古文 + AI 视频”本身已经被大量账号验证；
- 课本古文题材已经被教程化、提示词模板化和批量复制；
- “选了课本古文”不构成差异化；
- 选题库本身也不是护城河。

因此 V1 真正要验证的不是：

> “古文 AI 视频有没有流量？”

而是：

> **在一个已经拥挤的赛道里，电影感叙事、跨镜头一致性、系统化视觉设计与商业交付能力，是否能带来用户可感知、客户愿意付费的质量差异。**

如果这条核心假设不成立，即使偶尔出现爆款，也不视为项目模式成立。

---

# 3. 为什么仍值得测试

虽然题材本身不稀缺，但这个方向仍有四个值得验证的结构性优势：

1. **认知基础强**：经典文学、古文、名著天然拥有记忆和情绪基础；
2. **视觉化空间大**：许多文本过去受制作成本限制，没有被高质量影像化；
3. **内容库存长期稳定**：课本、诗词、古文、名著、神话、志怪、历史名场面可持续供给；
4. **B 端复用场景较多**：文旅、博物馆、出版、教育、城市文化、非遗、国风品牌等都可能使用同类能力。

但上述全部只是“值得验证的条件”，不是商业成功结论。

---

# 4. V1 不做什么

30 天 MVP 明确不做：

- 不开发 App / 小程序 / SaaS；
- 不自研视频生成基础模型；
- 不绑定 Seedance、Kling、Wan 等单一供应商；
- 不先做几十集连续 AI 微短剧；
- 不购买商业影视 IP；
- 不把 Prompt 当护城河；
- 不把首月粉丝数作为唯一目标；
- 不因为作品“看起来很酷”就提前扩大投入。

# 5. 三层商业模型

## 5.1 第一层：内容账号

目标不是只赚平台分成，而是：

- 验证题材和叙事；
- 获取自然流量；
- 沉淀品牌；
- 建立公开作品案例；
- 为 B 端获客提供可信作品集。

主要平台：抖音、快手、B站、小红书、视频号。

海外 YouTube / TikTok 暂不作为 V1 运营重点。

## 5.2 第二层：AI 文化影像制作服务

潜在客户：

- 文旅景区 / 城市文旅；
- 博物馆 / 文化馆；
- 出版社；
- 教育品牌 / 教育内容机构；
- 非遗项目；
- 国风消费品牌；
- 游戏 / 文化娱乐公司。

卖点不是：

> “我们会用 AI 做视频。”

而是：

> **“我们能把历史、文学、地域文化故事转化为可传播的电影感短片。”**

## 5.3 第三层：长期视觉 IP / 数字内容

只有 V1 验证成立后才考虑：

- 系列长视频；
- 经典文学影像课程；
- 出版 / 教育授权；
- 多语种海外版本；
- 角色视觉 IP；
- 文创或互动内容。

V1 不为这些方向提前开发产品。

# 6. 30 天 MVP

## 6.1 预算

现金预算：**约 5,000 元人民币**。

建议结构：

| 项目 | 预算 |
|---|---:|
| AI 视频生成 | ¥2,500 |
| 图片 / 角色参考 | ¥500 |
| 配音 / 声音 | ¥300 |
| 音乐 / 素材 | ¥300 |
| 工具会员 | ¥400 |
| 废片 / 重试储备 | ¥1,000 |
| 合计 | ¥5,000 |

人工工时不计入现金预算，但必须完整记录。

## 6.2 内容量

目标：

- 20–24 条 30–90 秒短内容；
- 2 条 3–10 分钟精品中视频；
- 每约 5 条内容做一次数据复盘；
- 不机械追求日更。

如果第 1 周发现精品路线的真实成本远超预算，不自动加钱，而优先减少产量、优化废片率或重新评估经济性。

# 7. 首批选题：主力与对照组

首轮审核后已经调整优先级。

## P0 主力

1. **《木兰诗》**：人物、战争、动作、情绪兼具；
2. **《赤壁赋》**：氛围、人物情绪、文化感和电影摄影空间强；
3. **《蜀道难》**：视觉奇观明显，适合测试 AI 的大场景优势。

## P1 探索

4. **《滕王阁序》**：建筑、盛宴、城市与大场景美术。

## Control 红海对照组

5. **《桃花源记》**。

《桃花源记》不再作为“最值得主打”的题材，而是故意选择一个已经高度同质化的题材，用来回答：

> **如果题材完全不新，我们的制作质量还能不能被明显识别出来？**

# 8. 第一周最重要的实验：差异化不能靠自我感觉

## 8.1 同题材 A/B

至少选择 2 个题材，各制作两种处理：

- A：History AI 电影感版本；
- B：市场常见“快节奏解读 / 翻译 + AI 画面”版本。

尽量控制题材、时长和发布时间窗口。

比较：

- 前 3 秒留存；
- 完播率；
- 分享率；
- 收藏率；
- 关注转化；
- 评论质量；
- 是否有人主动提到“电影感、质感、画面、想看完整版”。

## 8.2 非团队成员盲测

正式扩量前进行 20–30 人盲测。

混入：

- History AI 作品；
- 3–5 条市场同类 AI 古文作品。

隐藏账号、粉丝量、作者和制作方式。

核心问题：

1. 哪条最像真正影视作品？
2. 哪条最愿意看完？
3. 哪条最愿意分享 / 收藏？
4. 哪条最愿意继续看系列？
5. 为什么？

## 8.3 差异化 Gate

- **PASS**：盲测明显领先，公开数据也至少出现同方向正信号；
- **CONDITIONAL**：只有盲测或只有公开数据支持，继续小规模优化，不扩量；
- **FAIL**：两边都无法证明电影感带来增益，暂停高成本精品路线。

**单条爆款不能绕过这个 Gate。**

# 9. 制作系统：真正验证的是“可重复质量”

标准流程：

```text
原著 / 史料
  ↓
版权与事实边界检查
  ↓
内容目标
  ↓
60–90 秒剧本
  ↓
Storyboard
  ↓
Character Bible
  ↓
Visual / Scene Bible
  ↓
关键帧 / 参考图
  ↓
镜头级模型路由
  ↓
视频生成
  ↓
配音 / 音效 / 音乐
  ↓
剪辑 / 字幕 / 调色
  ↓
AI 标识 / 版权检查
  ↓
多平台发布
  ↓
数据与成本复盘
```

真正需要沉淀的是：

- 剧本改编方法；
- Storyboard；
- Character Bible；
- Visual Bible；
- 镜头路由经验；
- 生成失败数据；
- 剪辑和声音 SOP；
- 商业客户案例；
- 系列品牌认知。

Prompt、单条脚本、公共选题清单、单一模型技巧都不视为长期护城河。

---

# 10. 多模型策略

不规定一整条片必须使用同一个模型。

按镜头类型路由：

| 镜头 | 首要指标 |
|---|---|
| 人物近景 / 对白 | 身份一致性、表情、口型 |
| 人物动作 / 战斗 | 动作连贯、物理合理 |
| 大场景 / 奇观 | 构图、空间、运镜 |
| 风景 / 氛围 | 光影、材质、稳定性 |
| 长镜头 | 时间一致性 |
| 有声镜头 | 音画同步 |

Seedance / Kling / Wan 等不提前固定永久角色。

首片前用同一批代表镜头做小样测试，记录：

- 成片质量；
- 失败率；
- 生成次数；
- 实际成本；
- 可用秒数。

---

# 11. 成本验证

核心成本指标不是平台标称“生成 1 秒多少钱”，而是：

> **Cost per Usable Second：每一个最终可用成片秒的真实成本。**

每条作品记录：

- 脚本工时；
- 分镜工时；
- 关键帧成本；
- 每镜头生成次数；
- 废片次数；
- 模型费用；
- 声音费用；
- 后期工时；
- 总现金成本；
- 总人工时长；
- 最终可用秒数。

第一周就重新估算剩余三周预算，不等到最后才判断商业经济性。

---

# 12. B 端获客：不允许只等自然询盘

V1 采用：

> **Inbound + Outbound 双轨。**

## 12.1 Inbound

通过公开内容、作品集和账号案例产生自然询盘。

## 12.2 Outbound

第 1 周建立至少 30 个潜在客户名单。

优先三类：

1. 文旅 / 城市文化；
2. 博物馆 / 文化馆；
3. 出版 / 教育内容机构。

第 2–4 周过程目标：

- ≥30 个潜在客户；
- ≥10 次有效主动触达；
- ≥5 次有效回复 / 沟通；
- ≥2 次需求访谈；
- ≥1 份真实报价 / 提案。

90 天挑战目标：

> **首笔 ≥10,000 元文化 / 文旅 / 教育 AI 影像订单。**

但万元订单不再是唯一成败标准。付费小单、明确采购意向、进入采购/投标流程都属于强商业信号。

---

# 13. B 端真正要验证什么

每次客户沟通至少记录：

- 当前制作预算；
- 当前供应商和制作方式；
- 是否允许使用 AI；
- 最看重质量、速度还是价格；
- 决策链和采购周期；
- 是否要求公司资质 / 招投标 / 过往案例；
- 可接受交付周期；
- 对版权、历史准确性和品牌安全的顾虑；
- 对 Demo 的真实评价；
- 是否愿意付费试单。

这部分数据与播放量同等重要。

---

# 14. 平台与海外

国内 MVP：

- 抖音 / 快手：30–90 秒发现型内容；
- B站：3–10 分钟精品版本；
- 小红书：成片 + 制作过程 / 审美 / 教育属性；
- 视频号：文化、教育和潜在 B 端人群。

海外暂不运营，但从第一天保留：

- 无硬字幕母版；
- 中文字幕文件；
- 独立中文旁白音轨；
- 可翻译脚本；
- 专有名词表。

这样后续进入 YouTube / TikTok 时不需要重做素材结构。

---

# 15. 合规边界

当前已明确：

1. 古典原著可能进入公有领域，不代表现代影视改编可自由复制；
2. 不复制现代演员形象、服装、美术、音乐、配音、海报、游戏/动漫角色设计；
3. AI 生成内容按现行规则进行显式 / 平台所需标识；
4. 不恶意隐藏 AI 生成身份；
5. 连续微短剧不是 V1 路线，后续如进入，单独处理备案 / 审核 / 节目编号等要求；
6. 真人配音或真人声音克隆必须明确授权；
7. AI 音色需记录来源和商用条款。

# 16. 30 天判断标准

## A：扩大投入

出现以下一种或多种情况：

- 差异化盲测 PASS；
- 多条内容稳定获得较强完播 / 收藏 / 分享；
- 用户主动要求同系列、完整版；
- 成本可控且可重复生产；
- 获得明确 B 端试单或强采购信号。

## B：继续小规模迭代

- 数据存在亮点，但差异化证据不稳定；
- 精品质量有效，但成本过高；
- B 端有兴趣但采购链较长；
- 需要进一步缩窄题材或制作标准。

## C：暂停当前方向

如果完成约 20 条内容后仍同时出现：

- 用户无法感知精品版与普通 AI 古文内容的明显差异；
- 完播 / 分享 / 收藏弱；
- 制作成本明显不具备商业经济性；
- B 端访谈没有真实付费意愿；
- 没有形成可复制的内容结构。

则停止继续加预算，重新评估方向。

# 17. 当前最可能失败的三个地方

### 失败 1：电影感只是团队自我感觉

作品制作更慢、更贵，但普通用户并不明显偏好。

### 失败 2：内容有流量，但没有商业转化

账号数据不错，却没有任何客户愿意为相同能力付费。

### 失败 3：成本不可复制

精品片能做出来，但每条需要大量人工和反复重生成，导致无法形成可持续业务。

---

# 18. 当前认为最可能形成壁垒的资产

按长期价值排序：

1. **真实 B 端客户案例与信任关系**；
2. **稳定可重复的电影化制作系统**；
3. **Character / Visual Bible 及跨作品视觉体系**；
4. **系列品牌认知**；
5. **真实生产数据、失败数据、模型路由经验**；
6. 内容运营和用户数据。

不认为以下内容能形成可靠壁垒：

- Prompt；
- 公共选题库；
- 单一爆款；
- 单个模型使用技巧。

5. 30 天 / ¥5,000 / 20–24 条是否足以做有效验证？
6. A/B + 盲测 + 平台数据的差异化验证是否足够严谨？
7. 《木兰诗》《赤壁赋》《蜀道难》作为 P0 是否合理？
8. 《桃花源记》作为红海对照组是否合理？

# 21. 当前决策门

多人评审完成前：

- 不规模化制作；
- 不开发软件平台；
- 不扩大预算；
- 不进入连续微短剧。

评审收敛后，如果没有新的核心 blocker，下一步直接进入：

> **首批 P0 题材 Production Package + 《桃花源记》对照实验 + 第 1 周真实生产验证。**

不再反复无限扩展商业方案。
