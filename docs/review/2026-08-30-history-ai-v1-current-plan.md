# History AI V1 当前方案

> 状态：待评估  
> 日期：2026-08-30  
> 分支：`develop`  
> 用途：本文件是 History AI V1 当前唯一方案入口，供外部评估使用。

---

# 1. 项目目标

History AI 希望验证一个内容与商业方向：

> 能否利用生成式 AI，把中国经典文学、古文、名著、神话、历史与文化故事制作成具有较高审美和叙事价值的短视频内容，并逐步形成可持续的内容流量、文化影像制作能力和长期视觉 IP。

第一阶段不开发 App、小程序、SaaS，也不自研视频生成模型。

暂定内容品牌：

> **课本电影院**

口号：

> **把你背过的文字，拍成电影。**

“课本古文”只是第一批高认知测试题材，不视为护城河。

---

# 2. 当前核心判断

AI 古文、经典文学视频已经不是蓝海。

因此 V1 不验证“AI 古文有没有人看”这种泛问题，而验证更具体的问题：

1. 我们制作的内容能不能在真实平台获得可重复的用户消费信号；
2. 哪些题材、叙事方式和视觉表达最容易起量；
3. 如果有流量，后续提高制作质量是否值得投入更多成本；
4. 如果内容和成本都成立，再验证 B 端客户是否愿意付费。

当前最大的未知不是完整商业模式，而是：

> **真实用户是否愿意持续消费这类 AI 中国经典文学影像。**

所以 V1 采用 **Traffic-First**。

---

# 3. V1 总体路线

```text
Phase 1：15–30 天真实流量验证
        ↓
Traffic Gate
        ↓ PASS
Phase 2：差异化 / 技术 / 成本验证
        ↓
Quality & Economics Gate
        ↓ PASS
Phase 3：精品案例 + B 端付费验证
        ↓
Commercial Gate
        ↓ PASS
Phase 4：扩大内容产能 / 商业销售 / IP 探索
```

当前只准备执行 **Phase 1**。

---

# 4. Phase 1：真实流量验证

## 4.1 周期

- **15 天做第一次判断**；
- 最长 **30 天**；
- 不机械要求一定做满 30 天。

如果 Day 15 已出现非常清晰的正向或负向信号，可以提前做 PASS / PIVOT / STOP。

## 4.2 预算

Phase 1 现金预算控制在：

> **¥2,000–3,000**

整个 V1 可以预留约 ¥5,000，但不一次性投入。

建议结构：

| 项目 | 预算 |
|---|---:|
| AI 视频生成与重试 | ¥1,200–1,800 |
| 关键帧 / 角色参考 | ¥200–300 |
| 配音 / 音效 / 音乐 | ¥200–300 |
| 工具会员 | ¥200–300 |
| 失败 / 重试机动 | ¥200–400 |
| 合计 | ¥2,000–3,000 |

人工工时不计入现金预算，但必须完整记录。

## 4.3 内容数量

目标：

> **10–15 条 30–60 秒短视频**

原则：

- 前 5 条建立初始数据 Baseline；
- 后 5–10 条根据真实数据集中测试更强方向；
- 不机械日更；
- 不为了凑数量牺牲基本质量；
- 如果第 8–10 条已经出现持续明显 FAIL，可以提前停止。

Phase 1 不强制制作 3–10 分钟中长视频。

---

# 5. 第一批内容实验

Phase 1 同时测试“题材”和“表达方式”。

## 5.1 第一批题材

### 《木兰诗》

验证：人物、动作、战争、亲情、身份冲突是否具有传播力。

### 《蜀道难》

验证：视觉奇观、大场景、空间感能否提高点击和停留。

### 《赤壁赋》

验证：氛围、美术、情绪型内容是否存在稳定用户空间。

### 《桃花源记》

作为高同质化题材，验证即使题材并不新，内容处理方式能否仍获得用户信号。

### 《将进酒》或《出师表》

验证：强情绪、高认知文本是否比纯视觉奇观更容易传播。

根据前 5 条数据，再决定是否加入《滕王阁序》《琵琶行》《岳阳楼记》或其他题材。

## 5.2 候选表达方式

至少覆盖三种：

### A. 电影化场景叙事

用人物、动作和具体事件推进，强化沉浸感。

### B. 视觉奇观 + 经典名句

节奏更快，以画面冲击和高认知原文形成记忆点。

### C. 情绪叙事 + 高审美画面

减少复杂连续剧情，更强调情绪、声音和文案。

必要时加入：

### D. 经典名场面重构

选择一个戏剧冲突强的瞬间做 30–45 秒独立片段。

Phase 1 不预设哪种模式一定正确，由真实数据决定后续重点。

---

# 6. Phase 1 制作质量线

第一阶段要保证“达到正常可发布质量”，但不把自己拖进过度工程化。

最低质量要求：

- 没有明显畸形、严重 AI 伪影或影响观看的穿帮；
- 同一条视频核心人物在关键镜头中基本可识别；
- 视觉风格基本统一；
- 字幕、旁白、音乐、音效达到正常发布水平；
- 叙事能看懂，或能形成明确情绪；
- 不直接复制现代影视、动漫、游戏中的受保护角色造型、美术或音乐；
- 不为追求 100% 一致性无限重生成。

Phase 1 不要求：

- 20+ 镜头长连续叙事；
- 每条视频都建立复杂 Character Bible；
- 每条都做完整多模型路由；
- 逐帧人工修补；
- 电影工业级参数化标准。

如果某个制作动作显著增加时间和成本，却没有证据表明能提升真实用户数据，Phase 1 不优先投入。

---

# 7. 发布策略

## 7.1 平台

建议至少使用两个短视频平台作为主要验证渠道：

- 抖音；
- 快手。

如果精力允许，可以低成本同步：

- B站；
- 小红书；
- 视频号。

不同平台数据单独判断，不简单相加。

## 7.2 Organic First

第一阶段以自然流量为主。

- 不用付费投流制造“内容有效”的假象；
- 如果后续测试投流，必须单独记录为 paid experiment；
- Organic 和 Paid 数据分开分析。

## 7.3 尽量稳定发布变量

尽量控制：

- 时长区间；
- 标题风格；
- 封面质量；
- 发布时间窗口；
- 标签数量；
- 账号定位和简介。

目的不是做学术实验，而是减少明显干扰因素。

---

# 8. Phase 1 数据指标

每条视频尽量记录发布后 2h / 24h / 72h 数据。

核心指标：

- 曝光 / 播放；
- 前 3 秒留存；
- 平均观看时长；
- 平均观看比例；
- 完播率；
- 分享率；
- 收藏率；
- 评论率；
- 关注转化；
- 主页访问；
- 用户是否主动点题、催更、要求完整版或要求继续做系列。

播放量重要，但不单独作为生死指标。

特别关注三类信号：

1. **观看质量**：用户是否真的看下去；
2. **传播价值**：是否愿意分享和收藏；
3. **系列需求**：是否愿意继续关注同类内容。

---

# 9. Traffic Gate

Phase 1 结束后不因为单条爆款直接判定成功。

## PASS

满足以下方向中的多个，并且可以重复：

- 至少 2–3 条不同作品明显高于账号自身 Baseline；
- 完播 / 平均观看比例出现持续正向信号；
- 分享 / 收藏明显高于普通发布；
- 出现稳定关注转化；
- 评论中出现明确的系列需求、点题和催更；
- 某一种题材或表达方式能在不同作品上重复跑出相近表现。

结论：进入 Phase 2。

## CONDITIONAL / PIVOT

出现部分正向信号，但：

- 只有单一题材有效；
- 只有某个平台有效；
- 有播放但收藏 / 分享 / 关注弱；
- 用户更喜欢某种与预期不同的表达方式。

结论：延长至 Day 30 或调整题材 / 表达后继续小规模测试。

## FAIL

如果 10 条左右内容经过至少一次有效调整后仍然：

- 基本没有观看质量改善；
- 分享 / 收藏 / 关注持续很弱；
- 评论中没有系列需求；
- 不同选题都无法重复出现正向信号；
- 数据主要依赖单条偶发曝光。

结论：暂停当前内容方向，不继续释放后续预算。

# 10. 从第一条视频开始记录成本

虽然 Phase 1 主要验证流量，但从 Day 1 就记录生产数据，避免后续无法评估经济性。

每条记录：

- 脚本工时；
- 分镜 / 提示词工时；
- 关键帧和参考图成本；
- 视频模型现金成本；
- 生成次数；
- 废片次数；
- 配音 / 音效 / 音乐成本；
- 后期工时；
- 总现金成本；
- 总人工工时；
- 最终可用视频秒数；
- Cost per Usable Second（CPUS）。

Phase 1 不设一个武断的 CPUS 生死阈值，但要尽早识别明显不可持续的制作方式。

---

# 11. Phase 2：流量通过后再验证质量差异

只有 Traffic Gate PASS 后才正式进入。

主要验证：

- 什么叫 History AI 的“电影感”；
- 8–12 镜头跨镜头一致性的真实可实现水平；
- 精品版与普通版的 A/B 差异；
- 30–50 人盲测；
- 提高质量带来的流量增益是否值得额外成本；
- 现金成本 + 人工工时是否可复制。

条件满足后，再考虑制作 **1 条 ≤5 分钟精品片**。

如果高质量路线成本过高、效果提升不明显，可以切换到：

> **高审美单镜头 / 组镜头 + 强叙事文案**

而不是继续死磕复杂连续叙事。

---

# 12. Phase 3：B 端商业验证

只有内容和质量 / 成本验证出现正向信号后，再系统推进。

优先从决策更快的中小 B 切入：

- 民营文旅项目；
- 国风消费品牌；
- 文化创业公司；
- 民营文化空间；
- 出版 / 教育内容工作室；
- 游戏 / 文化内容公司。

大型文旅局、公立博物馆、大出版社等可以作为需求访谈和中长期目标，但不把它们作为早期快速成交的唯一来源。

Phase 3 要回答：

1. 客户为什么付钱——质量、价格、速度、创意还是传播效果；
2. 客户愿意为哪类 Demo 付费；
3. 是否能形成真实试单；
4. 实际售价是否覆盖现金成本和人工成本；
5. 是否具备稳定交付能力。

建议目标：

- 90 天：争取真实付费试单，金额不限；
- 约 180 天：再挑战万元级正式订单。

---

# 13. 长期商业模型

如果前面三个阶段验证成立，History AI 才考虑形成：

### 第一层：内容账号

持续获得自然流量、用户资产、公开案例和品牌认知。

### 第二层：AI 文化影像制作服务

为文旅、文化、出版、教育、品牌、游戏等客户制作电影感文化短片。

### 第三层：长期视觉 IP / 数字内容

包括：

- 系列精品内容；
- 经典文学影像课程；
- 出版 / 教育授权；
- 海外多语种版本；
- 角色视觉 IP；
- 文创或互动内容。

V1 不提前投入第三层。

---

# 14. 合规与版权底线

从第一条视频开始执行：

- 按适用规则进行 AI 生成内容标识；
- 原则上只使用公有领域原文 + 原创剧本 / 视觉设计；
- 不复制现代电视剧、电影、动漫、游戏的角色设计、美术、配乐或演员形象；
- AI 配音必须确认音色来源和商用授权；
- 不未经授权克隆可识别真人声音；
- 涉及真实历史人物、民族、宗教、重大历史事件时增加内容安全和事实核查；
- 面向 B 端交付时明确素材、模型和最终作品的授权边界。

V1 不进入连续 AI 微短剧生产。

---

# 15. 当前明确不做

Phase 1 不做：

- App / 小程序 / SaaS；
- 自研视频模型；
- 连续几十集 AI 微短剧；
- 强制精品中长视频；
- 过度复杂 Character / Visual Bible；
- 逐帧修补和重后期工程；
- B 端完整销售体系；
- 海外正式运营；
- 大规模付费投流。

第一阶段原则只有一句：

> **先用真实市场数据证明“值得继续”，再增加复杂度。**

---

# 16. 希望评估的核心问题

请重点评估以下问题，而不是做文字润色：

1. 15–30 天、¥2,000–3,000、10–15 条短视频，是否足以验证真实流量？
2. 首批 5 个题材是否覆盖了足够不同的用户需求？
3. 当前“题材 × 表达方式”的实验设计是否合理？
4. Phase 1 的最低制作质量线是否过低或过高？
5. Organic First + 至少两个平台是否合理？
6. 当前数据指标能否判断用户是真喜欢内容，而不是只被 AI 猎奇吸引？
7. Traffic Gate 是否足以防止单条爆款误判？
8. 10–15 条内容是否太多、太少，还是合理？
9. 是否有任何问题必须在第一条视频发布前解决，否则会污染整个实验？
10. 有没有明显被忽略的版权、平台、账号冷启动或内容安全风险？
11. 如果流量验证通过，Phase 2 再验证电影感 / 一致性 / 成本的顺序是否合理？
12. 如果由你决定，现在是否应该停止继续讨论，直接开始 Phase 1？

---

# 17. 评估结论格式

请给出明确结论：

- **A. 通过，可以直接开始 Phase 1 流量验证**
- **B. 有条件通过，存在必须先修的 Phase 1 blocker**
- **C. 不建议执行，当前 Traffic-First 方案本身需要重新设计**

如果给 B，请严格区分：

### Blocker

不解决会导致 15–30 天真实流量实验得到错误结论的问题。

### 非阻塞优化

可以在发布后继续调整，不应该因此继续延迟上线的问题。

最后请回答：

> **如果这是你自己的 15–30 天时间和 ¥2,000–3,000 现金，你现在会不会直接开始做？为什么？**
