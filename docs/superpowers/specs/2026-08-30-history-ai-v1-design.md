# History AI V1 方案设计

> 状态：Draft / 待评审
> 日期：2026-08-30
> 项目：history-ai
> 阶段：商业可行性验证 + 内容 MVP

## 1. 目标与非目标

### 1.1 项目目标

History AI 的目标不是做一个“AI 视频工具”，而是验证一个内容与商业命题：

> 是否可以利用生成式 AI，以低成本持续生产高质量的中国经典文学/历史文化影像内容，并形成可复制的流量资产、商业制作能力和长期视觉 IP。

第一阶段只验证三件事：

1. 用户是否愿意持续观看、收藏、分享和点播这类内容；
2. 团队是否能以可控成本持续产出稳定质量的作品；
3. 是否能把作品案例转化为文化、文旅、教育等 B 端商业订单。

### 1.2 V1 非目标

V1 明确不做：

- 不自研视频生成基础模型；
- 不绑定单一模型供应商；
- 不开发 App / 小程序 / SaaS 平台；
- 不直接做几十集连续 AI 微短剧；
- 不购买商业影视 IP；
- 不以播放分成为唯一盈利模式；
- 不追求首月粉丝规模最大化，而追求验证内容模型是否成立。

## 2. 核心判断

### 2.1 市场判断

AI 视频生成已经从“技术演示”进入可用于专业内容生产的阶段。模型单次生成时长、参考一致性、音视频联合生成和编辑能力持续提升，视频模型本身正在快速商品化。

因此项目的竞争壁垒不能建立在“会不会用 AI 生成视频”上，而应建立在：

- 选题能力；
- 剧本改编能力；
- 分镜与审美；
- 人物、场景和世界观一致性；
- 内容系列化能力；
- 多平台运营；
- 商业客户转化；
- 长期积累的视觉资产与制作 SOP。

### 2.2 为什么选择中国经典文学/历史文化

相比原创短剧，经典内容有几个显著优势：

1. **故事经过长期验证**：大量经典文本拥有天然认知和情绪基础；
2. **内容库存巨大**：诗词、古文、名著、神话、志怪、历史名场面可形成长期供给；
3. **常青属性强**：不像热点内容快速衰减；
4. **用户圈层多**：学生、家长、教师、文史爱好者、国风用户、海外中国文化用户；
5. **商业延展强**：教育、出版、博物馆、文旅、城市宣传、非遗、游戏等均可复用；
6. **部分古典原著已进入公有领域**：但现代影视造型、音乐、美术、配音、改编版本等仍需单独避开侵权风险。

## 3. 项目定位

### 3.1 对外品牌定位

工作品牌：**课本电影院**

候选口号：

> 把你背过的文字，拍成电影。

更长期的母品牌可以使用 History AI，但第一阶段内容账号应使用更容易被普通用户理解的中文栏目品牌。

### 3.2 内容定位

第一阶段采用“双内容池”：

#### A. 语文课本 / 古文电影化（约 70%）

示例：

- 《桃花源记》
- 《滕王阁序》
- 《岳阳楼记》
- 《木兰诗》
- 《赤壁赋》
- 《蜀道难》
- 《琵琶行》
- 《梦游天姥吟留别》
- 《出师表》
- 《兰亭集序》

核心价值：认知度高、视觉化空间大、教育和文化商业价值强、竞争相对没那么拥挤。

#### B. 名著 / 历史 / 志怪名场面（约 30%）

示例：

- 大圣出世
- 大闹龙宫
- 女儿国
- 长坂坡赵云
- 空城计
- 风雪山神庙
- 黛玉葬花
- 聊斋《画皮》
- 山海经异兽
- 荆轲易水诀别

核心原则：

> 不按“第 1 集、第 2 集”拍完整连续剧，而按“一个经典事件 = 一部独立电影短片”生产。

这样可以降低连续叙事、一致性和监管复杂度，同时允许每个选题独立测试。

## 4. 产品结构：三层商业飞轮

History AI 不把自己定义成单一内容账号，而是三层业务共用一套生产能力。

### 4.1 第一层：内容账号

目标：

- 获得自然流量；
- 验证题材；
- 累积粉丝；
- 形成公开作品案例；
- 建立品牌认知；
- 作为 B 端获客渠道。

主要平台：

- 抖音：短内容发现和爆款；
- 快手：短内容分发与下沉覆盖；
- B站：3–10 分钟精品内容与核心粉丝沉淀；
- 小红书：成片 + 制作过程 + 家长/教育/审美人群；
- 视频号：家长、教师、文化从业者和 B 端客户；
- YouTube / TikTok：第二阶段验证中国文化出海。

### 4.2 第二层：AI 文化影像制作服务

目标客户：

- 文旅景区；
- 博物馆；
- 出版社；
- 教育品牌；
- 教育硬件；
- 城市宣传；
- 非遗项目；
- 国风品牌；
- 游戏/文化娱乐公司。

卖点不是“AI 生成视频”，而是：

> 把历史、文学、文旅故事转化为电影感短片。

第一笔商业目标：

> 90 天内获得第一笔 10,000 元以上的文化/文旅/教育 AI 影像订单。

### 4.3 第三层：长期视觉 IP 与数字内容产品

在内容模型被验证后再评估：

- 中国经典影像课程；
- 面向学校/出版社的内容授权；
- 系列长视频；
- 海外多语种版本；
- 角色视觉 IP；
- 联名/出版/文创；
- 经典文学互动产品。

V1 不投入开发这些产品，只保留演进接口。

## 5. 30 天 MVP

### 5.1 预算与产量

- 总实验预算：**5,000 元人民币**；
- 20–24 条 30–90 秒短内容；
- 2 条 3–10 分钟精品中视频；
- 每发布约 5 条进行一次复盘；
- 不要求每天机械日更。

预算建议：

| 项目 | 预算 |
|---|---:|
| AI 视频生成 | ¥2,500 |
| 图片/角色参考 | ¥500 |
| 配音/声音 | ¥300 |
| 音乐/素材 | ¥300 |
| 工具会员 | ¥400 |
| 废片/重试储备 | ¥1,000 |
| **合计** | **¥5,000** |

人工时间暂不计入现金成本，但必须记录制作工时，用于后续判断商业毛利。

### 5.2 第一批测试选题

首轮优先测试 5 个：

1. 《桃花源记》
2. 《滕王阁序》
3. 《木兰诗》
4. 《赤壁赋》
5. 《蜀道难》

原因：视觉奇观强、认知度高、彼此风格不同，适合验证“自然景观 / 战争 / 城市 / 梦境 / 人文叙事”等不同内容类型。

### 5.3 首月节奏

#### 第 1 周：基线测试

完成首 5 个题材，每个题材至少产出一条短版。

目标：找出明显更强的题材和叙事方式。

#### 第 2 周：复制强信号

把第 1 周数据最好的 2 个方向各扩展 2–3 个相邻选题。

#### 第 3 周：跨类型验证

加入西游、三国、聊斋/山海经等名著和志怪题材，验证是否存在更强流量池。

#### 第 4 周：精品化

把表现最好的 1–2 个主题制作成 3–10 分钟精品版，用于 B站、视频号和 B 端案例展示。

## 6. 内容生产流水线

### 6.1 标准 Pipeline

```text
原著/史料
  ↓
版权与事实边界检查
  ↓
内容目标（娱乐 / 教育 / 情绪 / 奇观）
  ↓
60–90 秒剧本
  ↓
Storyboard（8–15 镜头）
  ↓
Character Bible
  ↓
Scene / Visual Bible
  ↓
关键帧 / 参考图
  ↓
视频生成（多模型）
  ↓
声音 / 旁白 / 音效 / 音乐
  ↓
剪辑 / 字幕 / 调色
  ↓
AI 内容标识与版权自检
  ↓
多平台适配
  ↓
发布
  ↓
数据记录与复盘
```

### 6.2 Character Bible

每个反复出现的角色必须建立统一定义：

- 年龄；
- 身高/体型；
- 面部特征；
- 发型；
- 服饰；
- 道具；
- 身份与时代；
- 表演风格；
- 禁止出现的现代影视版本特征；
- 核心参考图。

Character Bible 是项目长期视觉资产，不应依赖某一模型的 Prompt 写法。

### 6.3 Visual Bible

每个系列要定义：

- 历史时代；
- 服装与建筑基线；
- 色彩氛围；
- 摄影语言；
- 光线；
- 材质；
- 镜头风格；
- 禁用风格。

例如《桃花源记》V1：

> 东晋写实古典电影、自然主义、东方山水构图、柔和晨雾、真实村落、克制神秘感；禁止仙侠游戏 CG、现代汉服棚拍感、过度魔幻特效。

### 6.4 模型策略

V1 不押宝单一厂商，优先建立模型路由思维。

候选：

- Seedance；
- Kling；
- Wan；
- 后续出现的其他高质量视频模型。

镜头级选择模型，根据：

- 人物一致性；
- 运镜；
- 动作；
- 音视频联合能力；
- 参考控制；
- 成本；
- 生成速度；
- 商用授权条款。

模型不是核心资产；剧本、分镜、Bible、Prompt Library、剪辑方法和数据反馈才是核心资产。

## 7. 第一部样片：《桃花源记》

### 7.1 内容目标

- 时长：60–75 秒；
- 类型：写实电影短片；
- 情绪：神秘 → 惊奇 → 温暖 → 怅然；
- 核心记忆点：“豁然开朗”；
- 不做逐句翻译，采用电影叙事。

### 7.2 结构

| 时间 | 内容 |
|---|---|
| 0–3s | 黑暗山洞，远处一线白光 |
| 3–8s | 渔人独舟进入桃林 |
| 8–13s | 两岸桃林、落英溪水 |
| 13–19s | 溪尽头出现山洞 |
| 19–24s | 渔人侧身进入黑暗 |
| 24–31s | 豁然开朗，全景揭示桃花源 |
| 31–38s | 良田、池塘、桑竹、炊烟、村落 |
| 38–45s | 村民停下动作望向渔人 |
| 45–52s | 设酒杀鸡招待 |
| 52–59s | 渔人离开，沿途留标记 |
| 59–67s | 再次寻找，山谷迷雾 |
| 67–75s | 桃林仍在，洞口消失；字幕“后遂无问津者” |

### 7.3 核心镜头原则

“24–31 秒的豁然开朗”必须是整条内容视觉和情绪最高点。前 24 秒的压缩、幽暗和未知，都服务于这一镜头的释放。

## 8. 数据指标与决策机制

### 8.1 不以粉丝数为第一指标

重点观察：

1. 完播率；
2. 分享率；
3. 收藏率；
4. 评论点播率；
5. 系列观看行为；
6. 主页访问和关注转化；
7. 私信/商务咨询；
8. 单条内容生产成本；
9. 可用成片平均重试次数；
10. 单分钟有效成片制作工时。

### 8.2 30 天分级判断

#### A 级：明确值得扩大

满足任一：

- 1 条 100 万+；
- 3 条 30 万+；
- 多个题材稳定 10 万+；
- 或虽播放略低但出现明显的高分享、高收藏、高点播和商务询盘。

动作：扩大产能，集中最强题材。

#### B 级：有信号但需优化

- 最好内容约 5–20 万；
- 完播/收藏/分享明显高于账号均值；
- 评论持续出现指定选题需求。

动作：进入第 2 个月，只优化表现最好的一到两个内容结构。

#### C 级：缺乏产品市场匹配

- 20+ 条后大部分低于 1 万；
- 完播弱；
- 收藏分享弱；
- 无点播；
- 无系列观看；
- 提升制作质量后仍无明显改善。

动作：暂停追加投入，重新评估定位，而不是继续靠加产量赌爆款。

> 阈值用于实验决策，不应机械跨平台横向比较；平台口径变化时以账号内部对照为主。

## 9. 商业化设计

### 9.1 第一阶段收入优先级

优先级从高到低：

1. B 端文化/文旅定制短片；
2. 品牌商单；
3. 出版/教育内容合作；
4. 平台创作者收益；
5. 用户付费/课程；
6. IP 授权与衍生品。

理由：首期账号规模有限，播放分成难以支撑公司；公开作品案例更有可能快速转化为制作订单。

### 9.2 B 端产品化

不要报价“AI 视频 X 元/秒”，而应包装为结果型产品：

#### 产品 A：文化名场面短片

- 30–60 秒；
- 单主题；
- 适合景区/博物馆/品牌社媒；
- 包含脚本、分镜、生成、配音、剪辑。

#### 产品 B：城市/景区历史复原片

- 60–180 秒；
- 包含史料研究、时代设定和场景复原；
- 可用于官方账号、展馆和活动。

#### 产品 C：系列文化内容

- 5–20 集；
- 统一视觉 Bible；
- 适合教育、出版、文旅长期运营。

V1 暂不固定正式报价；拿到真实询盘后，根据制作工时、生成成本、修订次数和版权需求形成成本模型。

## 10. 平台策略

### 抖音 / 快手

- 主时长：30–60 秒；
- 目标：发现用户、测试 Hook、追求自然扩散；
- 前 3 秒必须提供视觉或故事悬念。

### B站

- 60 秒短片可同步；
- 重点经营 3–10 分钟精品版；
- 增加幕后制作、原文对照、历史考据等内容；
- 目标：粉丝沉淀和内容品牌。

### 小红书

- 成片 + Storyboard + 制作过程；
- 强化审美、教育和创作者标签；
- 避免只发纯视频而缺乏可收藏信息。

### 视频号

- 同步精品内容；
- 强调家长/教师/文旅/文化行业可理解的表达；
- 作为 B 端客户触达渠道之一。

### 海外

第二阶段再测试：

- 英语旁白/字幕；
- 独立标题和叙事，不做机械翻译；
- 优先 Journey to the West、Mulan、Chinese mythology、Three Kingdoms 等已有海外认知的主题。

## 11. 合规与版权

### 11.1 AI 内容标识

所有 AI 生成/合成视频在发布时主动使用平台提供的 AI 标识能力，并保留必要的显式/隐式标识；不得主动删除或规避生成内容标识。

### 11.2 微短剧边界

2026-09-01 起实施的《微短剧发展管理办法》对“单集少于 20 分钟、主题主线明确、故事情节连续完整、人物角色突出”的剧集建立分类管理、审核/许可和播出要求，并明确 AI 制作微短剧应在每集明显位置添加提示标识。

因此 V1 优先生产：

> 独立文化影像短片 / 单一名场面 / 非连续剧集内容。

若后续进入连续短剧，应单独设计“微短剧合规方案”，不得直接沿用 V1 发布方式。

### 11.3 公版原著不等于无版权风险

即使使用已进入公有领域的古典原著，也不得直接复制或高度模仿：

- 现代电视剧/电影角色造型；
- 受保护的游戏、动漫视觉设计；
- 现代改编版本的原创剧情；
- 影视配乐；
- 演员肖像与声音；
- 现代插画、美术设计、字体等。

项目必须建立自己的 Character Bible / Visual Bible。

### 11.4 历史与文学真实性

每条内容标记其类型：

- 原著改编；
- 历史复原；
- 文学想象；
- AI 创意演绎。

避免把“文学设定”伪装成历史事实，也避免把创意画面包装成真实考古/史料证据。

## 13. V1 验收标准

### 商业验证

- [ ] 30 天内完成 20–24 条短内容；
- [ ] 完成 2 条精品中视频；
- [ ] 至少完成 4 个完全不同内容类型的测试；
- [ ] 有统一数据记录；
- [ ] 能明确判断 A/B/C 级结果；
- [ ] 90 天目标：获得首笔 ≥ ¥10,000 的商业订单。

### 生产验证

- [ ] 单条内容存在可重复 SOP；
- [ ] Character Bible 可跨镜头复用；
- [ ] Visual Bible 可稳定约束风格；
- [ ] 至少两家视频模型可替换；
- [ ] 记录生成重试率、现金成本和制作工时；
- [ ] 关键作品可在不依赖具体模型 Prompt 的情况下重制。

### 合规验证

- [ ] AI 标识流程固定；
- [ ] 版权来源与现代改编风险有检查项；
- [ ] 历史事实和文学演绎有明确区分；
- [ ] 连续微短剧在 V1 中不作为默认产物。

## 14. 关键风险

### 风险 1：内容看起来像“AI 演示”而不是作品

应对：优先投资剧本、镜头和声音，减少炫技镜头；AI 不作为主要卖点。

### 风险 2：视觉一致性不足

应对：Character Bible + Visual Bible + 参考图先于视频生成；必要时拆镜头，不追求一次长生成。

### 风险 3：成本被废片吞噬

应对：记录“最终可用秒数 / 总生成秒数”和重试次数，不用模型官方单价代替真实生产成本。

### 风险 4：播放很好但不赚钱

应对：从第一个月开始建设 B 端案例页和商业产品，而不是等百万粉再商业化。

### 风险 5：过早做平台或自动化工具

应对：只有当人工流程已经跑通且重复劳动明确后，才考虑开发内部 Agent / workflow。

### 风险 6：同质化竞争

应对：避开“随便把名著生成一遍”，强化独立美术语言、电影叙事和系列品牌。

## 15. 评审需要重点回答的问题

请评审者不要只评价“AI 视频是否有前景”，重点挑战以下假设：

1. “语文课本电影化”是否比普通 AI 名著短剧更有差异化和用户价值？
2. 30 天、¥5,000、20–24 条内容是否足以验证 PMF？
3. B 端文化/文旅订单是否真的可以成为早期现金流，而非想象？
4. V1 是否应该更早/更晚进入连续微短剧？
5. 现有 KPI 是否能避免被单条偶发爆款误导？
6. 版权、AI 标识、历史内容合规是否还有遗漏？
7. 哪些资产真正构成护城河，哪些只是可被模型升级快速替代？
8. 哪些内容类型最应该从首批 5 个选题中删除或替换？
9. 90 天“首笔万元订单”是否合理，应改成什么指标？
10. 若只允许投入 1 个人 + ¥5,000，哪些环节必须进一步删减？
